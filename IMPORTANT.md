# ⚠️ IMPORTANT

### Sharing rules for Tetoware

<p>
  <img src="https://img.shields.io/badge/content%20creators-no%20monetizing-d92b2b?style=for-the-badge" alt="Content creators: no monetizing">

</div>

---

Tetoware is free and it is meant to stay free for the people who use it. Please read the rules below before you share, showcase or build on it.

---

## 🎥 Content Creators & Script Showcasers

You are welcome to showcase Tetoware, but **you may not monetize access to it.**

| | Rule |
|:---:|---|
| ❌ | Do **not** place any provided script behind monetized links (Lootlabs, Linkvertise, etc.) |
| ❌ | Do **not** sell the scripts or charge for access to them |
| ✅ | Showcase and review them freely |
| ✅ | Share the official repository link |
| ✅ | Credit **InfinitelyMNDEV** and **Eclipse Team** |

---

## 🛠️ Script Developers

You can build on top of Tetoware, including making your own script **closed source.**

| | Rule |
|:---:|---|
| ❌️ | You **can't** make your script closed source |
| ✅ | Modify, fork and build on the templates and scripts |
| ✅ | Keep the MIT copyright and license notice in the parts you reuse |
| ❌ | Do **not** put the script behind a key system or call system |
| ❌ | Do **not** give credit to yourself for the original work |

---

## 📌 At a glance

| | Content Creators | Script Developers |
|---|:---:|:---:|
| Showcase / review | ✅ | ✅ |
| Monetized links | ❌ | ❌ |
| Closed source | n/a | ❌️ |
| Key / call systems | ❌ | ❌ |
| Claim the original work | ❌ | ❌ |
| Credit Eclipse Team | ✅ | ✅ |
